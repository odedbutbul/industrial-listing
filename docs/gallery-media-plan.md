# תמונות הגלריה בחנות — מ-eBay לספריית המדיה (תכנון, 15/10/2026)

> **סטטוס:** התכנון אושר ע"י עודד (15/10/2026). ההעלאה נבנתה (`job:woo-gallery -- --apply`) ונבדקה מול חנות מדומה בלבד (`scripts/test-woo-gallery.ts`, 22/22). **לא רץ בייצור** — רק באישור עודד, אחרי סיסמת אפליקציה ושינוי ה-theme.
> מחליף את ההחלטה מ-29/09/2026 ("הראשית יורדת לחנות, השאר מוצגות מ-eBay") — בקשת עודד, 15/10/2026.

## למה

- היום עמוד המוצר מציג את תמונות 2 והלאה מ-`i.ebayimg.com` (meta `_sync_gallery`). חיפוש תמונות בגוגל מייחס אותן לדומיין של eBay ולא לחנות.
- כשמודעה נגמרת או ש-eBay מוחק תמונה, היא נשברת באתר.
- בדוח הסריקה מ-15/10: 192 מתוך 231 תמונות במדגם של 40 מוצרים הגיעו מ-eBay.

## מה ה-theme עושה היום (נקרא בקוד, לא נערך)

`store-theme/inc/product.php` → `vz_product_gallery()`:
1. התמונה הראשית: `$product->get_image_id()` (קובץ בספרייה).
2. אחריה: כתובות מתוך `_sync_gallery`. נקלטות רק כתובות שמתחילות ב-`https://i.ebayimg.com/`.
3. **הגלריה של WooCommerce (`get_gallery_image_ids()` / `_product_image_gallery`) לא נקראת בכלל.**
4. alt לכל תמונה והסתרה (`_vz_img_alt`, `_vz_img_hidden`, ב-`inc/product-seo.php`) ממופים לפי מפתח:
   קובץ בספרייה = `a<attachment id>`, תמונה מ-eBay = מזהה התמונה של eBay (`/z/<id>/`).

**המשמעות:** בלי שינוי ב-theme, תמונה שתעלה לספרייה ותחובר למוצר פשוט לא תוצג. ה-theme צריך שינוי קטן (בהמשך המסמך), והוא צריך לעלות **לפני** שהסנכרון מתחיל להחליף מוצרים.

## התכנון

### 1. מה עולה
- כל כתובת ב-`_sync_gallery` של מוצר שנמצא בחנות, **חוץ מתמונות מוסתרות** (`_vz_img_hidden`, בדרך כלל תווית המחסן). מוסתרת לא עולה לאתר ונשארת ב-`_sync_gallery` כמו היום.
- הקובץ שיורד: `https://i.ebayimg.com/images/g/<id>/s-l1600.webp`. זה אותו קובץ שה-theme מציג היום כ-`src`, אז אין שינוי באיכות ואין קידוד מחדש. WordPress יוצר ממנו את הגדלים הקטנים.
- **בלי העלאה כפולה:** טבלה חדשה במערכת `woo_media` (מזהה תמונה ב-eBay ייחודי → attachment id בחנות, שם קובץ, מוצר ראשון, תאריך). תמונה שכבר עלתה, גם ממוצר אחר, לא עולה שוב. (meta על ה-attachment לא נשמר — wp/v2/media לא מקבל meta שלא נרשם בתוסף/theme; הטבלה היא הרישום, ובכל מוצר `_sync_gallery_media` שומר את הזוגות.)

### 2. שם קובץ ו-alt
- שם הקובץ: ה-slug של המוצר בחנות (חנות כבר ניקתה אותו) + המיקום בגלריה: `omron-e3x-nh11-photoelectric-switch-lot-of-3-2.webp`. עד 70 תווים, אותיות קטנות באנגלית.
- alt: מה שכבר כתוב ב-`_vz_img_alt` לתמונה הזו (במדגם: 197/197 כבר כתובים בחנות). אם אין, `"<שם המוצר> — photo N of M"`, כמו ה-alt האוטומטי של ה-theme. הוא נכתב גם ל-`alt_text` של הקובץ בספרייה.

### 3. איך מעלים
- **מומלץ:** `wp/v2/media` עם סיסמת אפליקציה (`lib/woo/wp-media.ts` קיים, משמש מוצרים ידניים). שולטים בשם הקובץ ובשדה ה-alt, וההעלאה עצמה **לא שומרת את המוצר**, ולכן לא מנקה את הקאש.
  - **חסר בשרת:** `WP_APP_USER`, `WP_APP_PASSWORD` לא מוגדרים ב-stock-sync. עודד יוצר סיסמת אפליקציה למשתמש Shop Manager בחנות ומוסיף אותם ב-xCloud. נכון לעכשיו גם העלאת תמונות למוצר ידני לא תעבוד בייצור.
- חלופה בלי סיסמת אפליקציה: `images: [{src}]` ב-wc/v3. WooCommerce מוריד בעצמו, אבל שם הקובץ נלקח מהכתובת (`s-l1600.webp`), כל ההורדות קורות בתוך בקשת שמירת המוצר (איטי, וזה מסתכן ב-timeout), ואין דרך להימנע מהעלאה כפולה. **לא מומלץ.**

### 4. החלפת המוצר (בסדר הזה, בלי שלב שבו המוצר נשבר)
1. מעלים את כל התמונות של המוצר. אם אחת נכשלת, המוצר לא מוחלף בריצה הזו.
2. עדכון אחד למוצר (wc/v3 batch, 10 בכל בקשה):
   - `images`: הראשית (אותו id) + ה-attachments החדשים לפי הסדר ב-eBay;
   - `_sync_gallery`: רק מה שלא עלה (מוסתרות), כדי שה-theme לא יציג פעמיים;
   - `_vz_img_alt` / `_vz_img_hidden`: **מוסיפים** מפתח `a<id>` עם אותו ערך לכל תמונה שעלתה. המפתחות הישנים לא נמחקים.
   - `_sync_gallery_media` (JSON): `[{ebayId, attachmentId}]`, מה שהסנכרון חיבר. משמש להשוואה בעדכונים הבאים.
3. קריאה חוזרת של המוצר ובדיקה שהגלריה שווה לתוכנית.

כלום לא נמחק: לא קבצים בספרייה, לא meta ולא כתובות.

### 5. ניקוי קאש (המשימה הראשונה)
- העלאת קובץ לספרייה לא שומרת את המוצר. רק שלב 4.2 שומר, פעם אחת לכל מוצר.
- הסדר המומלץ: קודם כל ההעלאות (מנות, בלי לגעת במוצרים), ואחר כך החלפת כל המוצרים **ברצף אחד** (כ-890 שמירות בכ-15 דקות). כך יש תקופה "קרה" אחת, וה-preloader מחמם אחריה, במקום ניקויים מפוזרים לאורך ימים.
- מועד: אחרי 04:30 UTC (בדיקת המודעות) ולפני מחזור החימום הבא של ה-preloader. את זה צריך לתאם עם סשן החנות.

### 6. אחרי המעבר: מוצר ש-eBay שינה בו תמונות (`lib/sync/woo-content.ts`)
- היום שדה `gallery` נבדק מול `_sync_gallery`. אחרי המעבר `_sync_gallery` כמעט ריק, וההשוואה הייתה מסמנת "נערך ידנית" ומפסיקה לעדכן.
- **נבנה:** במוצר שעבר, הגלריה בחנות נבנית מחדש מ-`_sync_gallery_media` + `_sync_gallery` ומושווית כקבוצה (הסדר המקורי לא נשמר בחנות). אם ה-`images` בחנות שונים ממה שהסנכרון חיבר — "נערך בחנות", לא נוגעים ומדווחים.
- כש-eBay שינה את התמונות: המוצר חוזר זמנית לכתובות eBay (`images` = הראשית בלבד, `_sync_gallery` = הרשימה החדשה, `_sync_gallery_media` = `[]`; הקבצים מתנתקים, לא נמחקים). הריצה הבאה של `job:woo-gallery` מעלה רק את החדשות ומשתמשת שוב בקיימות. כך יש שמירה נוספת אחת (ניקוי קאש) רק במוצר שבאמת השתנה.
- מוצרים חדשים (`woo-products.ts`): אותה העלאה כבר ביצירה, כולל התמונה הראשית עם שם קובץ תיאורי (היום היא יורדת דרך WooCommerce בשם `s-l1600`).

## שינוי נדרש ב-theme (לסשן החנות, לא בוצע כאן)

`inc/product.php` → `vz_product_gallery()`: אחרי התמונה הראשית, להוסיף את `$product->get_gallery_image_ids()` כפריטי `att` (עם `w`/`h` מ-`wp_get_attachment_metadata`), ורק אחריהם את כתובות `_sync_gallery`. `vz_img_key()` כבר מחזיר `a<id>` לקובץ, כך ש-alt והסתרה ימשיכו לעבוד דרך המפתחות שהסנכרון מוסיף. `vz_gallery_img` / `thumb` / `full` כבר תומכים ב-`att`.

- **תואם לאחור:** כל עוד לא הוחלף שום מוצר, לאף מוצר של הסנכרון אין gallery ids (במדגם: 0/40), והתצוגה לא משתנה.
- סכמת Product (`image` ב-`inc/product.php:289`) עוברת דרך אותה פונקציה, ולכן תקבל את הכתובות בחנות לבד.

## הרצה

```bash
npm run job:woo-gallery                              # תצוגה מקדימה (קריאה בלבד)
npm run job:woo-gallery -- --apply --ids=15,17,34,40,52   # 5 מוצרים
npm run job:woo-gallery -- --apply --all             # הכל — רק אחרי בדיקת ה-5
```
`--apply` בלי `--ids` / `--limit` / `--all` נדחה. בלי `WP_APP_USER` / `WP_APP_PASSWORD` נעצר לפני כל פנייה לחנות.

**בדיקה (חנות מדומה, `scripts/test-woo-gallery.ts`, 22/22):** תצוגה מקדימה לא כותבת · סדר eBay נשמר · מוסתרת נשארת ב-`_sync_gallery` · alt מועתק ל-`a<id>` והישנים נשארים · שם קובץ לפי slug ומיקום · alt בספרייה (מהחנות / אוטומטי) · תמונה משותפת לשני מוצרים עולה פעם אחת · אין WebP ב-eBay → JPEG המקורי (`.jpg`) · מוצר עם גלריית Woo קיימת לא נוגעים · תמונה שנמחקה ב-eBay → המוצר לא מוחלף, מה שעלה נשמר, ריצה חוזרת משלימה · ריצה שנייה לא מעלה שוב · כתיבה אחת (batch) רק למוצרים שהוחלפו · לוג לכל כשל · עדכון תוכן אחרי שינוי ב-eBay + העלאה של החדשה בלבד · גלריה שנערכה בחנות לא נדרסת.
